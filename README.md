# Portfolio de Paloma Ruiz Ramírez

Portfolio profesional construido con **Hugo**, diseñado para destacar una carrera dual como Desarrolladora Full Stack y Profesora.

## 🚀 Inicio Rápido

### Requisitos
- [Hugo](https://gohugo.io/installation/) (Versión Extended recomendada)

### Instalación
1. Clona el repositorio.
2. Ejecuta el servidor de desarrollo:
   ```bash
   hugo server -D
   ```
3. Abre `http://localhost:1313` en tu navegador.

## 📁 Estructura del Proyecto

- `archetypes/`: Plantillas para nuevos contenidos.
- `assets/css/styles.css`: Sistema de diseño centralizado (CSS Variables, Dark Mode).
- `content/`: Contenido en Markdown (proyectos, blog, experiencia).
- `layouts/`: Plantillas HTML y componentes (partials).
- `static/`: Archivos estáticos (imágenes, etc).

## 🛠️ Comandos Útiles

- **Crear un nuevo proyecto:** `hugo new projects/nombre-del-proyecto.md`
- **Crear un post del blog:** `hugo new blog/titulo-del-post.md`
- **Generar sitio estático:** `hugo --minify`

## 🌐 Despliegue en Netlify

Este proyecto está listo para ser desplegado en Netlify.
1. Conecta tu repositorio a Netlify.
2. El archivo `netlify.toml` configurará automáticamente los comandos de build y el directorio de publicación.
